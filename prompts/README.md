# Prompts

Copy-paste prompts for the workshop. Each demo file has:

- **From scratch:** paste into any AI chat (Claude, ChatGPT, Gemini, Copilot Chat) and it builds the whole app.
- **With the starter:** use it in an AI coding tool opened on this repo (Claude Code, Cursor, Copilot, Codex). It fills in the TODOs in `starter/`.
- **Three checks** to do before you run anything.
- **If it breaks:** follow-ups to paste back along with the exact error.

| File | What it's for |
|---|---|
| [00-template.md](00-template.md) | The fill-in-the-brackets prompt from the slides |
| [00-prompt-a-vs-b.md](00-prompt-a-vs-b.md) | The live "same request, two prompts" demo |
| [01-air-drawing.md](01-air-drawing.md) | Demo 1: air drawing |
| [02-rock-paper-scissors.md](02-rock-paper-scissors.md) | Demo 2: rock-paper-scissors vs. the computer |
| [03-rep-counter.md](03-rep-counter.md) | Demo 3: squat or push-up counter |

One habit from Anthropic's Claude Code docs: if you've corrected the AI twice on
the same problem, start a fresh chat with a better prompt instead of trying a
third correction.
